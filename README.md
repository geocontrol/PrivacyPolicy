# Privacy Policy Research Project

A research and code project exploring privacy policies across digital services and platforms.

## Project Structure

```
docs/   — documentation, research notes, briefs, and analysis
src/    — source code
```

## Overview

Under GDPR and similar regulations, online services must publish accessible privacy policies
detailing data collection, usage, processing, third-party sharing, and contact information.
This project researches and analyses those policies across multiple platforms.

See `docs/` for the ideation brief and research notes.
